# Audiodateien

Hier gehören die Musikdateien hin, die der Player auf `musik.html` abspielt.

Erwartet werden aktuell (Namen stehen in `assets/js/player.js`):

| Datei | Titel |
|---|---|
| `nachtschicht.mp3` | Nachtschicht |
| `betonliebe.mp3` | Betonliebe |
| `sirenen.mp3` | Sirenen |
| `schwarzlicht.mp3` | Schwarzlicht |
| `kaltstart.mp3` | Kaltstart |
| `morgengrauen.mp3` | Morgengrauen |

Solange eine Datei fehlt, läuft der Player im **Vorschaumodus**: Anzeige und
Animation laufen weiter, unter den Bedienknöpfen erscheint ein Hinweis.

Empfehlung: MP3 mit 192–256 kbit/s. Ein 8-Minuten-Set sind so rund 12–15 MB –
für ein Vorschau-Set reicht meist ein 2–3-minütiger Ausschnitt.
