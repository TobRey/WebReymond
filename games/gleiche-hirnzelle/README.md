# Gleiche Hirnzelle

Browsergame für genau zwei Personen (PHP, ohne Datenbank, Claude über das
offizielle Anthropic-PHP-SDK).

- `src/` – Quellcode der Web-App (Installationsanleitung: `src/INSTALLATION.md`)
- `build.sh` – erzeugt `build/gleiche-hirnzelle.zip` inkl. `vendor/`
  (Composer nötig), bereit zum Hochladen auf cPanel-Hosting.
