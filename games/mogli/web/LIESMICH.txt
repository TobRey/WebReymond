Mogli - Dschungellauf 3.0.0
===========================

Ein Jump'n'Run fuer den Browser. Renn nach rechts, spring, erreich die Flagge -
und bau deine eigenen Levels im Karten-Editor.
A browser platformer. Run right, jump, reach the flag - and build your own
levels in the map editor.


DEUTSCH
-------

INSTALLIEREN

  1. Diese ZIP-Datei auf deinem Webspace entpacken, zum Beispiel nach
     /public_html/mogli/
  2. Im Browser aufrufen: https://deine-domain.tld/mogli/

  Mehr ist nicht noetig. Es gibt keine Datenbank, keine Installation, keine
  Konfiguration.

WICHTIG: NICHT PER DOPPELKLICK OEFFNEN

  Das Spiel besteht aus JavaScript-Modulen. Browser laden die aus
  Sicherheitsgruenden nicht ueber file:// - ein Doppelklick auf index.html
  zeigt eine leere Seite. Es braucht immer einen Webserver. Zum Ausprobieren
  auf dem eigenen Rechner genuegt im entpackten Ordner:

      php -S localhost:8000
      python3 -m http.server 8000

SO WIRD GESPIELT

  Seit Fassung 3.0 laeuft Mogli nicht mehr von allein: du steuerst ihn, wie
  man ein Jump'n'Run eben steuert.

  Handy/Tablet:  links unten zwei Pfeile (laufen), rechts unten der grosse
                 Knopf (springen). Laenger druecken springt hoeher, kurz
                 tippen macht einen kleinen Hopser.
  Tastatur:      Pfeiltasten oder A/D zum Laufen, Leertaste oder Pfeil hoch
                 zum Springen. Esc pausiert.
  Gamepad:       Steuerkreuz/Stick zum Laufen, A zum Springen.

  Die Uhr startet mit deinem ersten Schritt und laeuft bis zur Flagge durch -
  auch wenn du stirbst. Gezaehlt wird nur die Zeit: je schneller, desto besser.

  Was dir unterwegs begegnet:

  - Smaragde geben Zeitgutschrift (eingestellt im Editor, ab Werk 1 Sekunde).
  - Stacheln und Gegner werfen dich zum letzten Checkpoint zurueck (oder zum
    Start). Auf die meisten Gegner kann man draufspringen.
  - Federn schleudern dich hoch, broeckelnde Bloecke zerfallen unter dir,
    bewegliche Plattformen tragen dich mit.
  - Schluessel oeffnen Tueren, Portale teleportieren dich, die Zielflagge
    beendet das Level.

  Wer ein Level schafft, schaltet das naechste frei.

LEVELS BAUEN: DER KARTEN-EDITOR

  Der Admin-Bereich liegt unter

      https://deine-domain.tld/mogli/admin/

  Zugangscode ab Werk: 6713 (aendern: siehe unten). Dort gibt es vier Reiter:

  FIGUR        eigene Bilder fuer Mogli selbst, samt Trefferflaeche
               (unveraendert aus Fassung 2).

  ELEMENTE     alles, was auf eine Karte kann. Je Element kannst du ein Bild
               hochladen (Groesse und Format egal, GIF nimmt das erste Bild)
               und eine Trefferflaeche einzeichnen - der Ausschnitt des
               Bildes, der wirklich zaehlt. Leere Plaetze behalten die
               mitgelieferte Grafik; das Spiel laeuft also auch ganz ohne
               Uploads.

  KARTEN       der Editor. Links die Palette, in der Mitte das Raster,
               rechts die Eigenschaften des gewaehlten Elements.

               - Element in der Palette waehlen, dann ins Raster klicken.
                 Boden, Plattformen, Broeckelbloecke und Stacheln lassen
                 sich als Rechteck aufziehen.
               - Klick auf ein platziertes Element waehlt es aus; dann
                 kannst du es ziehen, rechts seine Einstellungen aendern
                 (Tempo, Strecke, Sprungkraft, Ziel-Portal ...) oder mit
                 Entf loeschen.
               - Jedes Element hat ausserdem ein Notizfeld - nur fuer dich,
                 das Spiel liest es nicht.
               - "Start setzen" bestimmt, wo Mogli erscheint. Jede Karte
                 braucht genau eine Zielflagge.
               - Oben: Karten anlegen, umbenennen, ordnen (die Reihenfolge
                 ist die Levelfolge im Spiel), loeschen; Rastergroesse
                 (16/32/48 px) und Kartengroesse; "Testen" oeffnet das
                 Level direkt im Spiel.

  HINTERGRUND  eigene Hintergrundebenen mit Tempo (0 = steht still und
               fuellt den Bildschirm - ein grosses Dschungelbild passt
               hier direkt).

  Speichern sichert Grafik UND Karten in einem Schritt. Ohne PHP landet
  beides nur in deinem Browser; "Als Datei laden" gibt dir assets.json und
  maps.json zum Hochladen von Hand.

WELCHE BILDER DAS SPIEL GERN HAETTE (SPRITE-WUNSCHLISTE)

  Alles freiwillig - ohne Uploads spielt sich das Spiel mit der eingebauten
  Grafik. Alle Groessen erlaubt, GIF erlaubt (es zaehlt das erste Bild).
  Wichtig: Einzelbilder mit durchsichtigem Hintergrund, keine Sammelblaetter.
  Ein Blatt mit sechs Bauteilen auf Leuchthintergrund kann das Spiel nicht
  zerschneiden - bitte als sechs freigestellte Dateien.

  - Boden-Block        kachelbar, z. B. Erde mit Graskante (16 x 16 oder
                       groesser)
  - Plattform          schwebend, von unten durchspringbar; gern als
                       links/Mitte/rechts-Teile oder ein breites Bild
  - Broeckelblock      rissiger Block
  - Bewegliche Plattform
  - Stacheln           16 px hoch, beliebig breit
  - Feder              gern 2-3 GIF-Bilder
  - Smaragd
  - Schluessel
  - Tuer               zu und offen
  - Portal             gern GIF
  - Gegner Laeufer     gern GIF
  - Gegner Flieger     gern GIF
  - Checkpoint         aus und an
  - Zielflagge         gern GIF
  - Hintergrund        beliebig gross; Tempo 0 fuellt den Bildschirm

  Element-Bilder sind vorerst Standbilder: von einem GIF nimmt das Spiel das
  erste Bild. Die mitgelieferten Platzhalter zeigen, wo alles sitzt.

ZUGANGSCODE AENDERN

  In admin.php stehen oben zwei Konstanten:

      ADMIN_CODE  der Zugangscode (ab Werk 6713)
      ADMIN_SALT  beliebige eigene Zeichenkette; macht die Anmelde-Marke
                  unerratbar

  Beides mit einem Texteditor aendern, Datei hochladen, fertig.

WELTWEITE BESTENLISTE

  Jedes Level hat seine eigene Liste, sortiert nach Bestzeit. Der Eintrag
  passiert automatisch beim Zieleinlauf; der Name kommt aus dem Feld im Menue.

  Die Liste braucht PHP auf dem Server - das haben praktisch alle Webspaces
  (GoDaddy, IONOS, Strato ...). Gespeichert wird in data/scores.json neben
  score.php; der Ordner entsteht von selbst. Klappt das Schreiben nicht
  (Rechte!), zeigt das Spiel stattdessen eine geraetelokale Liste und sagt
  das ehrlich dazu.

  Wer mag, setzt in score.php DATA_DIR auf einen Pfad ausserhalb des
  Webordners.

EHRLICH GESAGT

  Die Zeiten werden im Browser der Spielenden gemessen. Wer will, kann mit
  einem einzigen Kommandozeilenaufruf eine erfundene Zeit schicken. score.php
  weist unsinnige Werte ab (unter 3 Sekunden, ueber 2 Stunden), begrenzt die
  Eintraege pro IP und laesst keine HTML-Zeichen in Namen zu - aber gegen
  jemanden, der es wirklich darauf anlegt, hilft das nicht. Die Liste ist zum
  Spass da, nicht als Urkunde.

NEUE FASSUNG HOCHGELADEN UND ES SIEHT AUS WIE VORHER?

  Das ist fast immer der Zwischenspeicher des Browsers. Er hat die alte
  index.html behalten und laedt dazu neuen Code - oder umgekehrt.

  Zu tun:
    1. Wirklich ALLE Dateien ersetzen, nicht nur die geaenderten. Besonders
       index.html und den ganzen Ordner src/.
    2. Die Seite hart neu laden:
         iPhone/iPad:  Einstellungen > Safari > Verlauf und Websitedaten
                       loeschen. Oder die Seite einmal in einem privaten Tab
                       oeffnen.
         Android:      im Menue der Seite auf "Neu laden" lange druecken.
         Windows/Linux: Strg + Umschalt + R
         Mac:          Cmd + Umschalt + R
    3. Notfalls die Adresse mit einem Anhaengsel aufrufen:
         https://deine-domain.tld/mogli/?neu=1

  Seit Fassung 2.0.3 wird jede Code-Datei mit ihrer Versionsnummer
  angefordert; ein alter Eintrag im Zwischenspeicher wird also gar nicht mehr
  getroffen.

  Zusaetzlich liegt eine .htaccess im Hauptordner. Sie sagt Apache, dass
  index.html nicht zwischengespeichert werden darf, und setzt fuer .js den
  richtigen Typ. Zeigt der Server nach dem Hochladen "Internal Server Error",
  erlaubt dein Hoster keine eigenen .htaccess-Regeln - dann diese eine Datei
  loeschen, das Spiel laeuft auch ohne sie.

  GEHT ES IMMER NOCH NICHT? DIE PRUEFSEITE FRAGEN

  Im Paket liegt pruefung.html. Sie gehoert nicht zum Spiel und prueft deinen
  Server von deinem Geraet aus durch:

      https://deine-domain.tld/mogli/pruefung.html

  Unten ist ein Knopf "Ganzen Bericht kopieren". Den Text einfach schicken -
  das sagt mehr als jede Beschreibung. Die Pruefseite danach wieder loeschen.

  Geht es trotzdem nicht, erscheint oben ein roter Streifen mit der
  Fehlermeldung. Diesen Text abfotografieren - darin steht, welche Datei fehlt
  oder wo es klemmt.

ENGLISH
-------

INSTALL

  1. Unzip this file onto your web space, e.g. /public_html/mogli/
  2. Open in a browser: https://your-domain.tld/mogli/

  That is all. No database, no installation, no configuration.

IMPORTANT: DO NOT OPEN BY DOUBLE-CLICKING

  The game is built from JavaScript modules, which browsers refuse to load
  via file:// - double-clicking index.html shows an empty page. You always
  need a web server. For a quick local try, run inside the unzipped folder:

      php -S localhost:8000
      python3 -m http.server 8000

HOW TO PLAY

  Since version 3.0 Mogli no longer runs on his own - you steer him.

  Phone/tablet:  two arrows bottom left (run), one big button bottom right
                 (jump). Hold to jump higher, tap for a small hop.
  Keyboard:      arrow keys or A/D to run, Space or Up to jump, Esc pauses.
  Gamepad:       d-pad/stick to run, A to jump.

  The clock starts with your first step and never stops until the flag -
  deaths included. Only time counts: the faster, the better.

  On the way: emeralds grant a time bonus; spikes and enemies throw you back
  to the last checkpoint (most enemies can be stomped); springs launch you,
  crumbling blocks give way, moving platforms carry you; keys open doors,
  portals teleport you, the goal flag ends the level. Finishing a level
  unlocks the next one.

BUILDING LEVELS: THE MAP EDITOR

  The admin area lives at https://your-domain.tld/mogli/admin/ (access code
  6713 by default; change ADMIN_CODE in admin.php). Four tabs:

  CHARACTER    custom images for Mogli himself, incl. hitbox.
  ELEMENTS     everything that can go on a map. Per element you may upload
               one image (any size or format, GIF takes the first frame) and
               draw its hitbox - the part of the picture that really counts.
               Empty slots keep the built-in art.
  MAPS         the editor: palette on the left, grid in the middle,
               properties on the right. Pick an element, click the grid;
               ground, platforms, crumbling blocks and spikes can be dragged
               out as rectangles. Click a placed element to select, drag or
               delete it, tune its settings (speed, range, spring power,
               portal target ...) and leave yourself a note (the game never
               reads it). "Set start" places Mogli; every map needs exactly
               one goal flag. The toolbar creates, renames, orders (order =
               level order in the game) and deletes maps, sets grid and map
               size, and "Test" opens the level right in the game.
  BACKGROUND   your own background layers with speed (0 = static, fills the
               screen - a big jungle picture fits here directly).

  Save stores graphics AND maps in one step. Without PHP everything stays in
  your browser; "Download as file" gives you assets.json and maps.json.

SPRITE WISHLIST

  All optional - the game plays fine with its built-in art. Any size, GIF
  allowed (first frame counts). Important: single images with transparent
  background, no sprite sheets - the game cannot cut up a sheet of six parts
  on a glowing background; please export them as six separate files.

  Ground block (tileable), platform (floating, one-way), crumbling block,
  moving platform, spikes (16 px tall, any width), spring (2-3 GIF frames),
  emerald, key, door (closed and open), portal (GIF), walking enemy (GIF),
  flying enemy (GIF), checkpoint (off and on), goal flag (GIF), background
  (any size, speed 0 covers the screen).

WORLDWIDE LEADERBOARD

  Every level has its own list, sorted by best time; entries are submitted
  automatically when you reach the flag. It needs PHP on the server (nearly
  every web space has it). Times are stored in data/scores.json next to
  score.php. If writing fails, the game falls back to a per-device list and
  says so honestly.

HONESTLY

  Times are measured in the player's browser. Anyone determined enough can
  submit a made-up time with a single command line call. score.php rejects
  nonsense values, rate-limits per IP and strips HTML from names - but the
  list is for fun, not a certificate.

FILES

  index.html      the page
  pruefung.html   server self-check; delete after use
  style.css       looks
  src/            the game code (JavaScript modules)
  admin/          the admin area (character, elements, maps, background)
  admin.php       accepts graphics pack and maps (access code!)
  assets.php      serves the graphics pack to the game
  maps.php        serves the maps to the game
