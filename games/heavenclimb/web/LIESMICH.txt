HeavenClimb 1.0.0
=================

Ein Jump'n'Run fuer den Browser. Klettere so hoch du kannst.
A browser platformer. Climb as high as you can.


DEUTSCH
-------

INSTALLIEREN

  1. Diese ZIP-Datei auf deinem Webspace entpacken, zum Beispiel nach
     /public_html/heavenclimb/
  2. Im Browser aufrufen: https://deine-domain.tld/heavenclimb/

  Mehr ist nicht noetig. Es gibt keine Datenbank, keine Installation, keine
  Konfiguration.

WICHTIG: NICHT PER DOPPELKLICK OEFFNEN

  Das Spiel besteht aus JavaScript-Modulen. Browser laden die aus
  Sicherheitsgruenden nicht ueber file:// – ein Doppelklick auf index.html
  zeigt eine leere Seite. Es braucht immer einen Webserver. Zum Ausprobieren
  auf dem eigenen Rechner genuegt im entpackten Ordner:

      php -S localhost:8000
      python3 -m http.server 8000

WELTWEITE BESTENLISTE

  Liegt score.php mit auf dem Server und ist PHP aktiv, tragen sich alle
  Spielenden in eine gemeinsame Bestenliste ein. Gespeichert wird in einer
  einfachen Datei unter data/scores.json – keine Datenbank noetig.

  Zu tun:
    - Das Verzeichnis data/ muss fuer PHP beschreibbar sein:
          chmod 755 data
      Manche Hoster verlangen 775 oder einen bestimmten Besitzer.
    - In score.php ganz oben RATE_SALT auf einen beliebigen eigenen Zufallstext
      aendern. Er sorgt dafuer, dass IP-Adressen nur als Hashwert gespeichert
      werden.

  Kein PHP vorhanden oder data/ nicht beschreibbar? Dann laeuft das Spiel
  trotzdem vollstaendig. Die Bestenliste schaltet automatisch auf "Nur auf
  diesem Geraet" um und speichert im Browser. Im Spiel steht sichtbar, welcher
  Modus gerade laeuft.

  Bei nginx statt Apache greift die mitgelieferte data/.htaccess nicht. Dort
  gehoert in die Serverkonfiguration:

      location ~ /data/ { deny all; return 404; }

  Wer die Punktestaende lieber ganz ausserhalb des Webverzeichnisses ablegt,
  setzt in score.php die Konstante DATA_DIR auf einen absoluten Pfad.

EHRLICH GESAGT

  Die Punkte werden im Browser der Spielenden berechnet. Wer will, kann mit
  einem einzigen Kommandozeilenaufruf eine erfundene Zahl schicken. score.php
  weist unsinnige Werte ab, begrenzt die Eintraege pro IP und laesst keine
  HTML-Zeichen in Namen zu – aber gegen jemanden, der es wirklich darauf
  anlegt, hilft das nicht. Die Liste ist zum Spass da, nicht als Urkunde.

STEUERUNG

  Laufen          Pfeiltasten oder A / D
  Springen        Leertaste, W oder Pfeil hoch (halten = hoeher)
  Doppelsprung    in der Luft noch einmal springen
  Wandsprung      an einer Wand herunterrutschen, dann springen
                  (laedt den Doppelsprung wieder auf)
  Durchfallen     Pfeil runter oder S auf einer duennen Plattform
  Pause           Esc oder P
  Neu starten     R
  Ton aus         M

  Handy: die Flaechen unten links und unten rechts.
  Gamepads werden unterstuetzt.

DATEIEN

  index.html        die Seite
  style.css         Gestaltung
  score.php         Bestenliste (optional)
  data/             wird von score.php angelegt, gehoert nicht ins Backup
  src/              der Spielcode

  Sprache umschalten: oben rechts, DE oder EN. Die Wahl wird gemerkt.


ENGLISH
-------

INSTALL

  1. Unzip this archive into your webspace, e.g. /public_html/heavenclimb/
  2. Open https://your-domain.tld/heavenclimb/ in a browser.

  That is all. No database, no installation, no configuration.

IMPORTANT: DO NOT OPEN BY DOUBLE-CLICKING

  The game uses JavaScript modules, which browsers refuse to load over
  file:// for security reasons — double-clicking index.html shows a blank
  page. A web server is always required. To try it locally, run inside the
  unpacked folder:

      php -S localhost:8000
      python3 -m http.server 8000

WORLDWIDE LEADERBOARD

  If score.php is uploaded and PHP is enabled, all players share one
  leaderboard. It is stored in a plain file at data/scores.json — no database.

  To do:
    - data/ must be writable by PHP:  chmod 755 data
      Some hosts require 775 or a specific owner.
    - Change RATE_SALT at the top of score.php to any random text of your own.
      It keeps IP addresses stored as hashes only.

  No PHP, or data/ not writable? The game still runs completely. The
  leaderboard falls back to "This device only" and stores scores in the
  browser. The game shows which mode is active.

  On nginx the bundled data/.htaccess has no effect. Add to your server config:

      location ~ /data/ { deny all; return 404; }

  To keep scores outside the web root entirely, set the DATA_DIR constant in
  score.php to an absolute path.

HONESTLY

  Scores are computed in the player's browser. Anyone can send a made-up
  number with a single command-line call. score.php rejects implausible
  values, rate-limits per IP and strips HTML from names — but none of that
  stops someone determined. The list is for fun, not for records.

CONTROLS

  Move            Arrow keys or A / D
  Jump            Space, W or Up (hold to jump higher)
  Double jump     press jump again in mid-air
  Wall jump       slide down a wall, then jump
                  (this refills the double jump)
  Drop through    Down or S while on a thin platform
  Pause           Esc or P
  Restart         R
  Mute            M

  Phone: the areas at the bottom left and bottom right.
  Gamepads are supported.
