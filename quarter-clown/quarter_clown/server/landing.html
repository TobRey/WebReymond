Für Windows herunterladen
3

Ausprobieren ohne zu warten: /quarter testmodus takt:10 Sekunden

Fragen

Windows sagt „Der Computer wurde durch Windows geschützt“

Das kommt bei neuen Programmen ohne gekauftes Zertifikat. Klicke auf Weitere Informationen und dann auf Trotzdem ausführen.

Was wird aufgenommen? Was passiert mit den Daten?
  • Die App nimmt nur die sichtbare Discord-Ansicht und den Discord-Ton auf deinem PC auf – erst, wenn alle im Call zugestimmt haben.
  • Es wird keine komplette Aufnahme gespeichert. Nur das fertige Meme geht an Discord.
  • Neue Leute im Call pausieren die Aufnahme, bis sie zustimmen. Jede:r kann sofort stoppen.
Kostet das was? Brauche ich KI?

Nein. Die Memes funktionieren mit eingebauten Brainrot-Vorlagen. Wer will, trägt in der App einen eigenen Anthropic-API-Key ein – dann schreibt Claude die Captions.

Quarter Clown · Nutzt nur die offizielle Discord-Bot-API.
