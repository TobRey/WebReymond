# Eigene Reaktionsbilder

Leg hier eigene lustige Bilder (PNG/JPG/WEBP) ab. Bei Vergleichs-Memes
(„er im call:“ / „er innerlich:“) nimmt Quarter Clown sie zu 70 % statt der
eingebauten Paint-Fratzen.

Passend zum Gesichtsausdruck in Unterordner sortieren:

| Ordner      | wird genommen bei              |
|-------------|--------------------------------|
| `scream/`   | Lachen, Schreien, laut, Chaos  |
| `stare/`    | nichts los, leerer Blick       |
| `cry/`      | Grimassen, Verzweiflung        |
| `smug/`     | Grinsen                        |
| `shock/`    | Schock, Bildwechsel, Gesten    |

Bilder direkt in `stickers/` passen zu allem. Nimm nur Bilder, die du verwenden darfst.
