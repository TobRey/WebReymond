# Custom Paintings (Minecraft 1.21.1, NeoForge)

Eigene Bilder auf ganz normalen Minecraft-Gemälden.

1. Gemälde wie gewohnt aufhängen – es erscheint wie immer ein zufälliges Minecraft-Motiv.
2. Gemälde anschauen und **Shift + Rechtsklick**.
3. **„Bild auswählen …“** oder die Bilddatei einfach ins Fenster ziehen (PNG, JPEG, BMP, GIF).
4. Anpassung wählen – Standard **„Füllen (zuschneiden)“**: das Bild füllt das Gemälde immer komplett,
   überstehende Ränder werden mittig abgeschnitten. Alternativ „Einpassen (Ränder)“ oder „Strecken“.
5. **„Übernehmen“** – alle Spieler in der Nähe sehen das Bild, auch wer später dazukommt.
   **„Original“** stellt das Minecraft-Motiv wieder her.

Die Größe des Gemäldes (1×1 bis 4×4 Blöcke) bestimmt das Format; das Bild wird mit 64 Pixeln pro Block
gespeichert (einstellbar). Abbauen gibt wie immer ein normales Gemälde zurück.
